# Clone Pinterest

Dashboard de inspiración visual adaptable a dispositivos móviles, con búsqueda de imágenes, vista de detalle y guardados locales.

## Uso

Abre `index.html` en un navegador moderno o sirve el directorio con cualquier servidor estático. Se necesita conexión a internet para consultar imágenes de Wikimedia Commons. Escribe una búsqueda y pulsa Enter; también puedes elegir un tema sugerido. Los guardados se almacenan en el navegador del dispositivo y no se sincronizan entre dispositivos.

## Imágenes

La aplicación consulta la API pública de Wikimedia Commons y muestra resultados cuyo metadato de licencia indica dominio público o CC0. Abre el enlace de cada imagen para revisar su autoría y las condiciones concretas en su página de origen. Los resultados dependen del catálogo y de la disponibilidad del servicio; no es una búsqueda en Pinterest.

Proyecto independiente, sin afiliación con Pinterest.
