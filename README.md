# Clone Pinterest

Dashboard de inspiración visual desarrollado con React y Vite, adaptable a dispositivos móviles, con búsqueda, vista de detalle y guardados locales.

## Ejecutar el proyecto

Requisitos: Node.js y npm instalados.

```bash
npm install
npm run dev
```

Abre la dirección local que muestra Vite. Para generar una versión de producción, ejecuta `npm run build`; los archivos se generan en `dist/`.

Escribe una búsqueda y pulsa Enter, o elige un tema sugerido. Los guardados se almacenan en el navegador y no se sincronizan entre dispositivos.

## Imágenes

La aplicación consulta la API pública de Wikimedia Commons y muestra resultados cuyo metadato de licencia indica dominio público o CC0. Se necesita conexión a internet. Abre el enlace de cada imagen para revisar su autoría y sus condiciones en la página de origen. Los resultados dependen del catálogo y de la disponibilidad del servicio; no es una búsqueda en Pinterest.

Proyecto independiente, sin afiliación con Pinterest.
